# Full-Stack E-Commerce Web Application

A modern, full-stack E-Commerce platform built with **React**, **Node.js / Express**, and **Java Spring Boot**.

## 🌟 Key Features
- 🛒 **Shopping Cart & Checkout Wizard**
- 📱 **Interactive Payment Suite**: Supports UPI (VPA, QR Code scanning, Quick App launchers), Credit/Debit Cards, NetBanking, Cash on Delivery (COD), and PayPal.
- 🚚 **Order Management**: Status tracking, cancellation with refund notification, and return/replacement requests.
- 🎨 **Modern Dark UI**: Designed with glassmorphism aesthetics, responsive layouts, and rich micro-interactions.
- ⚡ **Dual Backend Support**: Run with Node.js/Express backend or Java Spring Boot backend.

## 🚀 Quick Start

### 1. Run Node.js Backend + React Frontend
```bash
# Terminal 1: Node.js Backend (Port 5000)
npm run start:node

# Terminal 2: React Frontend (Port 3000)
npm run start:frontend
```

### 2. Run Java Spring Boot Backend + React Frontend
```bash
# Terminal 1: Spring Boot Backend
npm run start:spring

# Terminal 2: React Frontend (Port 3000)
npm run start:frontend
```
